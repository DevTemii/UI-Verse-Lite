# UIverse Lite 🌙

A collection of clean, reusable, production-ready UI components built with minimal CSS.
Perfect for frontend devs, designers, and hackathon projects.

## ✨ Features
- 6 small, modern UI components (Button, Card, Navbar, Hero, Footer, Badge)
- Fully responsive with lightweight CSS
- Copy-paste ready HTML snippets
- Open-source & community-driven

## 📦 What’s included
- `index.html` — demo page showcasing components
- `components/` — individual component HTML files (copy-paste ready)
- `assets/css/styles.css` — minimal styles used by components
- `screenshots/header.png` — demo screenshot / hero image

## 🚀 How to use
1. Clone the repo:
```bash
git clone https://github.com/YOUR_USERNAME/uiverse-lite
cd uiverse-lite
```
2. Open `index.html` in your browser to see the demo.
3. Copy individual component files from `/components` into your project or paste code snippets directly.
